# Nuxt Tour is in design

Nuxt Tour will provide accessible, route-aware product tours with a Vue-native
API and a Nuxt-first developer experience.

The package is not published. The repository currently contains the operational
foundation, proposed public contract, and implementation plan. It intentionally
does not contain a partial tour engine.

## Read the specification

- Start with [Product and scope](/docs/design/product-and-scope).
- Review the [Public API](/docs/design/public-api).
- Check the [Runtime semantics](/docs/design/runtime-semantics).
- Follow the [Implementation plan](/docs/implementation).

## Definition of ready

The first usable package must complete a same-page semantic-target tour from a
clean Nuxt application. It must then prove route transitions, late targets,
cleanup, keyboard operation, focus restoration, reduced motion, and packed
consumer installation before the first public release.
