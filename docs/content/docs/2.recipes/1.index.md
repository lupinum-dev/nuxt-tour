# Explore production tour patterns

Use these recipes when the first tour is working and you need a production
pattern. The lab below runs the real library. It does not simulate the overlay
or card.

::tour-recipe-gallery
::

## Choose a recipe

- [Add images and rich content](/docs/recipes/rich-content) with a normal Vue
  component.
- [Move across routes and dynamic targets](/docs/recipes/routes-and-targets)
  without timing guesses.
- [Prepare and conditionally include steps](/docs/recipes/conditions-and-preparation)
  with cleanup that runs exactly once.
- [Choose an interaction mode](/docs/recipes/interaction-and-focus) for modal,
  target, or page interaction.
- [Brand the card and translate labels](/docs/recipes/customization) without
  replacing the accessible host.
- [Observe events and record progress](/docs/recipes/events-and-progress)
  without coupling the library to an analytics provider.

Each recipe uses the same four concepts: `defineTour()` describes,
`<TourHost />` renders, a composable controls, and a semantic target locates.
