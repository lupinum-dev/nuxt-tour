# Public API

This page defines the implemented version 1 contract.

## Tour definition

```ts
export default defineTour({
  id: 'getting-started',
  steps: [
    {
      id: 'welcome',
      ariaLabel: 'Welcome',
      content: 'Welcome to the application.',
    },
    {
      id: 'projects',
      route: { name: 'projects' },
      target: 'new-project',
      title: 'Create a project',
      content: 'Start your first project here.',
      placement: 'bottom-start',
      prepare: async ({ signal }) => {
        const panel = useProjectPanel()
        panel.open()
        await nextTick()

        if (signal.aborted) return
        return () => panel.close()
      },
    },
  ],
})
```

`defineTour()` preserves literal tour and step IDs. Every definition has at
least one step. Tour IDs and step IDs are unique.

## Step contract

```ts
interface TourStep {
  id: string
  target?: TourTarget
  route?: RouteLocationRaw
  title?: string
  ariaLabel?: string
  content: string | Component
  placement?: Placement
  offset?: number
  scroll?: false | ScrollIntoViewOptions
  interaction?: 'blocked' | 'target' | 'allowed'
  when?: (context: TourStepContext) => boolean | Promise<boolean>
  prepare?: (
    context: TourStepContext,
  ) => void | (() => void) | Promise<void | (() => void)>
}
```

An omitted `target` means an intentionally centered step. A requested target
that does not exist never falls back to the center.

`interaction: 'target'` requires a target. The other modes also work for
centered steps.

A visible `title` names the dialog. A step without a title requires an
`ariaLabel`. Runtime validation rejects empty names.

## Target contract

```ts
type TourTarget =
  | string
  | {
      id: string
      timeout?: number
      missing?: 'skip' | 'error'
    }
  | {
      selector: string
      timeout?: number
      missing?: 'skip' | 'error'
    }
```

A string is a semantic target ID. The engine resolves it from
`data-tour-target` or the target registry.

```vue
<button data-tour-target="new-project">New project</button>
```

Dynamic Vue elements register the same semantic ID:

```ts
const trigger = useTemplateRef<HTMLElement>('trigger')
useTourTarget('new-project', trigger)
```

Direct refs do not belong in `TourStep.target`. The registry connects local Vue
state to stable tour definitions. Selector objects are an explicit escape hatch
for third-party or legacy markup.

## Controller

```ts
const tour = useTour('getting-started')

tour.status
tour.currentStep
tour.currentStepId
tour.index
tour.total
tour.pending

await tour.start()
await tour.start({ at: 'projects', replace: true })
await tour.next()
await tour.previous()
await tour.goTo('projects')
await tour.skip()
await tour.cancel('application-state-changed')

const stop = tour.on('step:show', event => {
  console.log(event.stepId)
})
```

`useTour()` is the only imperative control plane. Components do not expose a
second controller through template refs. Navigation uses stable step IDs, not
numeric indexes.

`index` is zero-based and refers to the definition order. `total` includes
conditional steps, including steps skipped at runtime. This avoids evaluating
all conditions early only to calculate progress.

## Exports

The package root exports the Nuxt module and `ModuleOptions`. The `/vue` entry
exports:

```text
defineTour
useTour
useTourTarget
TourHost
TourContent
createTourPlugin
vTourTarget
TourError
TourErrorCode
public TypeScript types
```

The CSS entries are `@lupinum/nuxt-tour/style.css` and
`@lupinum/nuxt-tour/structure.css`.

The default theme follows `prefers-color-scheme`. Class-based applications can
set `.light` or `.dark`; attribute-based applications can set
`data-theme="light"` or `data-theme="dark"`. Application CSS can override the
low-specificity `--tour-*` custom properties without `!important`.

In a plain Vue application, pass a definition to `useTour()` for complete tour
and step-ID inference. String tour IDs remain runtime-validated. Nuxt generates
application-specific declarations, so Nuxt consumers also get autocomplete for
string tour IDs.
